# Usage notes

This package was prepared for the TerraOI identity project. Original editable geometry and templates are included for adaptation and updates. The earlier raster board is a generated visual reference. No trademark registration, legal clearance, exclusive ownership, or third-party brand rights are asserted by this package.

No third-party font binaries, map tiles, stock photos, or external runtime libraries are bundled. The terrain illustration in HTML is original schematic SVG; the concept-board terrain is part of the generated reference image. Customer Brand is a replaceable demonstration identity, not a real customer claim.

Only finalized and populated customer-facing files should be sent to end customers. This complete kit includes provider guides and development sources.
