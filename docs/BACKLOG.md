# BACKLOG: owner decisions and unowned work

A register, not a decision. Two things land here and nowhere else: **(D)** a decision or human-only step that only the repository owner can take, and **(U)** work the plan asks for that no packet owns, or that a packet owns but cannot start until something specific merges. Rows are pointers, not arguments: the argument belongs in the issue, the packet or the PR the row names.

Rules that keep this file honest:

- **A row never replaces an issue, a label or a packet edit.** If a row needs a supervisor decision, it still needs a `needs-supervisor` issue ([COORDINATION §6](COORDINATION.md)); if it needs a contract change, a `needs-contract` issue and an ADR ([COORDINATION §2](COORDINATION.md)). This register only makes sure such a thing is *not forgotten between sessions*, which is the failure mode it was written for.
- **A row is never restated as open once it is decided.** The "already decided" list at the bottom exists so the next agent does not re-litigate it. Delete a row when its issue closes or its PR merges; a stale row is worse than no row.
- **No row authorises anything.** Nothing here lets an agent touch production, a secret, another lane's files or another packet's body ([FAQ-0007](FAQ.md)).
- Read the board live before acting on a row: `gh pr list --repo TerraOI/TerraOI --state open`, `gh issue list --repo TerraOI/TerraOI --state open`, `git log --oneline origin/main`. The file was drafted against `origin/main` = `10868ad` on 2026-11-12/13 and re-read at registration on **2026-11-15**, when the board was **17 open PRs** — 13 draft (#138 #139 #149 #150 #151 #158 #160 #168 #173 #179 #181 #186 #187) and 4 ready (#143 #162 #172 #178) — and **8 open issues** (#176 #177 #180 #182 #183 #184 #185 #188).
