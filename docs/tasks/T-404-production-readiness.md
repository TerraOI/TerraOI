## Goal

Move TerraOI from "deploys to staging when a secret happens to exist" to "a release to production is a written, rehearsed, reversible procedure with named human steps". Three deliverables: the **configuration and scripts** an agent can write and test (a `wrangler.jsonc` production environment, an environment-hygiene preflight, a rollback helper, a migration-sequence check), the **runbooks** that make §17.2 executable by a person, and **one rehearsal on staging** — the restore of database, auth dependencies and object references into an isolated environment, plus the rollback of an app release and of an index pointer — whose evidence goes in the week-4 register.

**What this packet is not:** the go-live. Every step below marked `OWNER` needs account access, a secret, DNS, or a production write, and plan §20.8 says agents must not do them. A packet that pretends otherwise produces a checklist nobody can execute and a production incident with no owner.

## Contract

Nothing new in `src/contracts/`. The contract here is procedural, and it is §17.2 plus §16's Operations row:

- **Forward-compatible migrations only.** `scripts/migrations.mjs:33-37` already enforces one new, later-timestamped migration per PR; the rollback rule that follows from §17.2 is that an app rollback must not require a schema rollback — a migration that breaks the previous app version is a cutover, and a cutover needs the owner's decision and a frozen artifact pair.
- **Rollback is an app artifact plus an index generation, never "the last deploy".** The retained pair is (tagged release commit + `wrangler` version id) × (the pinned `embedding_indexes` generation per [ADR-0007](../decisions/0007-e1-embedding-clearance.md)); "App/DNS rollback does not undo database, published-source or external-action changes" (§17.2) is written into the runbook as a rule with a check, not a remark.
- **Restore is database + auth dependencies + object references + permission state**, asserted afterwards: revoked sources still refused, stale jobs cannot resurrect them, no signed URL survives in any row (#10), and the two staging tenants still resolve to their own data.
- **Preflight is a gate, not a notice**: a mismatch fails the job and no deploy step runs.
