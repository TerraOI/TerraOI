# Fonts

Preferred interface font: Inter. Preferred data font: IBM Plex Mono.

This offline kit does not distribute font binaries. It uses Arial and Consolas fallbacks so it can be reviewed without installation. Word templates use Arial and Courier New for portability. The core logo wordmark is drawn as SVG paths and does not depend on fonts. Descriptor text in SVG full lockups is editable text with an Arial fallback.

Obtain preferred fonts from the maintainers before self-hosting or distributing them, and retain the license files accompanying the chosen release:

- Inter: https://github.com/rsms/inter
- IBM Plex: https://github.com/IBM/plex

After installing or embedding the selected fonts, recheck line breaks in all screens, emails, and exported documents. Email clients may substitute system fonts even when web fonts are available.
